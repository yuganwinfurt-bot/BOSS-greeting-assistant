# BOSS 打招呼助手

当前版本 v1.5.76，包含第一阶段账号安全修复及设置页、网页和后台的性能优化。

## 安装或升级

1. 在 Edge 打开 `edge://extensions/`，或在 Chrome 打开 `chrome://extensions/`。
2. 如果已经从本目录加载本扩展，在原有扩展卡片上点击“重新加载”，再刷新旧的 BOSS 标签页。这样可以保留同一扩展的本地配置和历史。
3. 首次使用时，在开发人员模式中选择“加载解压缩的扩展”，选择本目录。只启用一个 BOSS 助手。
4. 在基础配置中设置 AI 接口、导入可复制文字的 PDF 简历，并添加岗位画像或用简历一键生成。扫描版 PDF 需先在本机转成可复制文字。配置导出文件可能含 API Key 和简历文本，请私下保管。

## 搜索与人工沟通

- 在“搜索方案”选择城市、求职类型和薪资范围。岗位名称用作搜索词，岗位要求用于 AI 匹配。单方案中先按城市、再按岗位顺序搜索。
- “确认后保存待沟通”会在当前搜索项结束后等待你选择岗位或点击“跳过并继续搜索”。“自动保存匹配岗位”会把匹配岗位加入本地沟通记录。
- 从“沟通记录”打开 BOSS 官方岗位页，由你确认和发送。开启“AI 招呼语草稿”后，可按岗位生成可复制的文本。列表来源的草稿使用岗位列表摘要，详情页手动保存的候选可包含详情。
- “结果未知”表示旧版沟通可能已经发生。先打开 BOSS 聊天记录核对，确认确实已沟通后再点击“标记已人工核对”。已保存候选及未知结果都不计作新发送。
- 已有的 PDF 简历、一键生成岗位、AI 接口、两套提示词、配置导入导出、屏蔽和历史记录仍可使用。默认官方 Flash 推理强度为 High。

## 暂停和恢复

- 设置页顶部“运行安全”显示状态、发生时间、搜索条件、任务编号和是否有待处理项。
- 遇到平台限制、身份验证或关键沟通提示时，由你在 BOSS 官方页面处理。网络异常和超时会另行显示，也会暂停当前流程。
- 在扩展设置页点击“我已核实，恢复任务”，确认后从未完成的搜索项重新扫描。当前步骤里的 AI 结果以已经保存的识别记录为准，没有页内断点。
- 关掉活动搜索页或重启浏览器时，任务可能进入暂停。后台重启和看门狗不会解除暂停。升级前的未完成沟通会保留为待办或结果未知。
- 本版本仍会自动搜索和翻页。站点规则、页面变化和账号状态会影响运行，建议先在离线样本中验证所用浏览器上的表现。

## 项目结构

- `src/` 保存扩展 JavaScript，包括后台、页面桥和内容脚本。
- `pages/` 保存设置页、识别页和样式。
- `tests/` 保存离线回归与性能基准，`docs/` 保存报告。
- `vendor/` 与 `store-assets/` 分别保存第三方依赖和扩展图标。加载扩展时仍选择含 `manifest.json` 的项目根目录。
