# v1.5.76 专项性能测试报告

日期为 2026-11-12。基线取桌面项目优化前的 v1.5.75 源码，候选取最终集成的 v1.5.76。四组数据均为合成记录，没有读取或写入用户浏览器的实际存储。

## 无头 Chrome 离线界面测试

使用同版本 Chrome/157.0.8103.52、独立浏览器配置、真实 DOM 与 Mock Chrome 扩展存储。脚本通过 CDP 拦截页面请求，只返回合成页面、脚本和样式。每个版本每种规模跑一轮。计时从设置脚本初始化开始，基础表单就绪由 MutationObserver 记录，未计入浏览器启动和脚本加载时间。堆数据为依次打开各标签页并触发 GC 后的 JS 堆，不是进程总内存或运行峰值。

| 合成识别记录 | 基础表单就绪 ms | 优化后首次打开屏蔽页 ms | 屏蔽记录第二页 ms | GC 后 JS 堆 KiB | 屏蔽数 / 沟通数 |
|---:|---:|---:|---:|---:|---:|
| 1,000 | 3,711.5 → 6.0 | 11.1 | 2,444.0 → 1.3 | 1,455 → 1,563 | 990 / 368 |
| 3,000 | 10,948.8 → 4.2 | 26.4 | 7,247.4 → 1.1 | 3,726 → 3,931 | 2,866 / 368 |
| 7,000 | 25,290.1 → 4.4 | 51.5 | 16,807.9 → 1.0 | 8,244 → 8,573 | 6,619 / 368 |
| 15,000 | 54,473.4 → 5.6 | 87.6 | 35,911.0 → 1.2 | 17,383 → 17,891 | 14,127 / 368 |

合成数据含 366 条已沟通来源记录、少量本地待沟通及结果未知记录、64 条手动屏蔽和 1 条屏蔽公司。筛选后的屏蔽数和输入规模不同，两个版本的界面计数逐项相同。基线在首屏已渲染所有历史面板，切到已渲染标签页的计时很短，但计算已计入首屏。优化版首屏只渲染基本页。同一轮遍历四个标签页，Mock storage 读从 10 次降到 3 次，写入均为 0。15,000 条的首次历史打开仍需约 87.6 ms。热分页复用排序结果。缓存保留排序结果和身份索引，15,000 条的 GC 后 JS 堆实测增加约 508 KiB。

| 1,000 | 906.5 → 5.4 | 877.0 → 0.12 | 14.70 → 1.02 | 925 |

比较全部四组 AI 排除结果的有序身份摘要、第二页 HTML 的 SHA-256、沟通条数和每页行数，均一致。回归还覆盖了旧版 ID、URL、标题与公司匹配，结果未知、已人工确认、历史重复、源数据不变。

BOSS 网页部分使用 Node DOM Mock。6,913 条手动屏蔽、366 条沟通记录、67 张卡片，连续 8 轮过滤从 1,381.53 ms 降至 31.12 ms。卡片选择器调用 4,224 → 2,584，URL 解析 1,175,765 → 16,392。隐藏状态和历史判断逐项一致。实时预览的同帧合并、勾选与滚动保留、关闭后监听释放、XHR 复用和响应上限均通过 Mock。此处不代表真实 BOSS 页帧率或长期内存。

- 原有安全回归 18 项，新增 11 项，合计 **29 项通过，0 失败**。
