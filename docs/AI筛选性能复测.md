# AI 筛选性能复测

日期 2026-11-13。原版是本轮开始前桌面的 v1.5.76（已包含分阶段超时修复）。新版是本轮性能改动。两边都使用 Node.js 24.21.0 的单机计时，平台和模型请求均为 Mock。每组 3 次，按端到端耗时取中位数，对应行内阶段来自同一次运行。

测试从当前搜索项已进入采集函数开始，到岗位结果处理和可选返回首页完成。包含实际的扩展采集、筛选、解析和历史合并代码。每项 3 页、每页 12 个不同岗位，另有 7,000 条模拟历史。翻页固定约 85 ms，稳定等待以相同的 400 ms 模拟，后接实际 350 ms 轮询。历史存储用 structuredClone 模拟序列化，DOM 卡片用 JS 对象模拟。浏览器布局、IPC、真实站点网络和下一城市完整加载时间待验证。

## 暂停与剩余问题

- 设置页的「AI 筛选已暂停」对应 ai-error，包括缺少接口配置、超时、断流或消息丢失、HTTP 错误及模型漏答。慢请求达到超时或返回异常后才会暂停。待人工沟通仅是本地状态。BOSS 的访问限制、频率限制和身份验证单独处理。
- 正常页面桥且无自动交接时，耗时改善主要来自减少历史读回，缓存全中组没有明显改善。后台仍按批次全量写回历史，页面首次仍读全量历史，以保留历史顺序、人工覆盖、即时保存和数据兼容。
- 正常前进翻页沿用 200–599 ms 稳定等待和 350 ms 轮询。新搜索页等待沿用 500 ms 轮询和 300 ms 交接定时。只有确知有下一搜索且无需人工审核时跳过返回首页。城市导航请求、目标页面加载和真实浏览器布局成本待验证。
- 批次大小、AI 并发、超时、推理配置、筛选提示词和平台安全规则沿用原值。
